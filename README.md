# FitLog 🏋️

FitLog is a modern workout library and fitness companion that helps users discover exercises, view workout details, and organize workouts into their daily plan. It provides a simple and focused way to explore different exercises and keep track of training.

## 🚀 Technologies Used

* **Next.js** – React framework for building the web application
* **React.js** – For building reusable UI components
* **Tailwind CSS** – For responsive and modern styling
* **JavaScript** – Application logic and functionality
* **JSON Server / API** – For managing workout data
* **Netlify** – For deployment and hosting

## ✨ Key Features

1. **Workout Library**
   Browse a collection of workouts targeting different muscle groups, including chest, back, legs, arms, shoulders, core, and full body.

2. **Workout Details**
   View useful information about individual exercises, such as workout duration, estimated calories, equipment, and rating.

3. **Add to Today's Plan**
   Users can add their favorite workouts to their daily workout plan and organize what they want to complete.

4. **Save Workouts**
   Users can save workouts for quick access later instead of searching through the entire workout library again.

5. **Responsive Design**
   The website is designed to work across mobile, tablet, and desktop screen sizes for a smooth experience on different devices.
